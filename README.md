## Cómo revisarlo

1. Abrir los notebooks en Jupyter Notebook, JupyterLab o un entorno compatible.
2. Inspeccionar las dependencias y las rutas de entrada de datos antes de ejecutarlos.
3. Revisar el origen de los datos, las operaciones realizadas y las salidas del notebook.
4. Comparar las salidas obtenidas con las conclusiones del proyecto antes de citar métricas.

**Aviso:** no se ha ejecutado ni auditado el contenido de los notebooks como parte de esta mejora de presentación. No se garantiza reproducibilidad desde una instalación limpia.
